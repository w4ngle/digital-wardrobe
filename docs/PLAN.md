## 1. Модель разработки: спиральная (риск-ориентированная), 4 витка

| Виток | Срок | Цель | Главный риск | Инкремент | Критерий выхода |
|---|---|---|---|---|---|
| **0. Стабилизация** | 2 дня | Проект собирается с нуля, БД поднимается одной командой | Не воспроизводится репозиторий | `npm i && npm run build` зелёный | Чистая установка на втором компьютере |
| **1. «Описание вещи»** | ~1 нед. | Фото → структурированное описание + `description`, сжатие | Ошибки распознавания, дорогие фото | Добавление вещи с ИИ-описанием | ≥ 85 % правильных категорий на 30 фото |
| **2. «Подбор по тексту»** | ~1,5 нед. | «Собери образ на свадьбу» → набор вещей с объяснением | Галлюцинации id, бессмысленные сочетания | Экран «Подбор»: текст → образ + причины | 0 несуществующих id, ≥ 80 % уместных образов |
| **3. «Поиск, погода, картинка»** | ~1 нед. | Семантический поиск (pgvector), учёт погоды, коллаж | Стоимость генерации картинок | Поиск «синяя футболка»; кнопка «на картинке ✦» | Стоимость замерена |
| **4. «Дизайн, защита»** | ~1 нед. | Дизайн-система, auth/RLS, деплой, demo-режим | Сбой сети/ключа на защите | Публичный URL, репетиция | Две репетиции без сбоев |

**Приоритеты (MoSCoW):**
- **Must:** Витки 0, 1, 2, оценка качества, auth/RLS, деплой, demo-режим.
- **Should:** семантический поиск, коллаж образа, дизайн-система.
- **Could:** ИИ-рендер картинки, погода, PWA, статистика носки.

## 5. Защита: метрики, сценарий, вопросы

### Метрики

| Метрика | Цель |
|---|---|
| Валидность JSON | 100 % (с повтором) |
| Точность категории/сезона/стиля | ≥ 85 % |
| Галлюцинации id | 0 |
| Уместность образа (оценка людей) | ≥ 4/5 |
| Доля откатов на правила | < 10 % |
| Задержка p50 / p95 | < 4 с / < 8 с |
| Стоимость | записать реальную |

### Сценарий демо (3 минуты)

1. Фото новой вещи → ИИ заполняет карточку → правка поля
2. Запрос «свадьба летом, прохладно» → образ + объяснение
3. «Заменить вещь» → образ пересобрался
4. Поиск «синяя футболка»
5. Кнопка «Показать на картинке ✦»
6. Слайд с метриками и стоимостью

### Вопросы жюри

- **«Что здесь делает ИИ?»** — Два шага: (1) фото → структурированное описание; (2) по описаниям компонирует образ; код проверяет результат.
- **«Почему не просто ChatGPT?»** — Модель работает с *вашим* каталогом, возвращает только существующие вещи, ответ валидируется, есть откат.
- **«Как боретесь с ошибками?»** — Подтверждение пользователем, `confidence`, схема + валидатор, повтор, откат, метрики.
- **«Сколько стоит?»** — Цифры из `ai_usage` (доли цента за подбор; картинка дороже → только по клику).
